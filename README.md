# 静心小院 · 立体试用版

本目录是独立静态站点，原平面版保存在 `lite/`，原始 `../site/` 未修改。

启动：在 `/workspace/jingxin` 运行 `python3 -m http.server 8080`，访问 `http://localhost:8080/site2/`。请通过 HTTP 服务打开，以便浏览器加载 ES 模块。

场景与人物均由代码中的几何体、材质和粒子原创组合生成，不使用外部图片、字体、模型或接口。唯一第三方运行库为本地 Three.js 0.170.0，许可见 `vendor/LICENSE.txt`。分享图由本地 Chromium 对实际三维场景截图生成。

使用方式：点击“进院坐坐”后开启音频权限；点击地面行走，拖动画面小范围平移，滚轮或双指缩放。静坐会走到自己的坐垫；可敲铜钵、选择 3/5/10 轮的 4-4-6 呼吸、泡茶或为他人留茶。雨声、溪水声、竹林风声可以分别开关及调节音量。晴雨按钮与雨声联动。所有音频由 Web Audio 实时合成，首次进入默认安静。

清晨（6–9 点）、白天（9–16 点）、黄昏（16–19 点）和夜晚按设备本地时间切换，每分钟刷新。夜间有暖窗、庭院灯和萤火虫。访客为本机模拟，显示人数与当前可见访客一致，数量保持 3–6，无聊天。每日留茶杯数以 `courtyard-tea-YYYY-MM-DD` 存于当前设备的 localStorage；存储不可用时当前会话仍可使用。不登录、不收集信息，无外部网络请求。

调试入口：`#scene=home`、`#scene=sit`、`#scene=breath`、`#scene=tea`、`#scene=night`、`#scene=rain`。呼吸和泡茶入口展示指定步骤，仍可手动开始完整流程。调试入口不会自动启动音频。`window.__sceneReady` 表示完成首帧，`window.__yardState()` 返回本机场景状态用于验收。

兼容措施：正交相机、像素比上限 2、1024 阴影贴图、静态模型按材质批处理、竹干竹叶 InstancedMesh、原生指针事件。页面隐藏时停止场景更新并暂停音频。WebGL 初始化失败自动跳转 `lite/`，保留 hash。音频不可用时仍可浏览。

验收截图在 `../shots2/`，检查记录在 `../check2.txt`。已通过 Chromium + SwiftShader 手机尺寸自动化验证；真实微信内置浏览器、iOS Safari 和安卓设备仍需实机体验，加载时间随设备与服务器变化。
