# 静心小院

纯静态单页试用版，无依赖、无构建步骤。使用系统字体，不访问外部网络。

- `index.html`：页面结构和分享元数据。
- `style.css`：手机优先布局、人物、器物和轻动画。
- `art.svg`：原创竹林、溪水、小院场景。
- `app.js`：静坐计时、4-4-6 呼吸、泡茶流程、设备内茶杯计数，以及 Web Audio 实时合成声音。
- `share.png`、`favicon.svg`：自绘分享图和图标。

在该目录运行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`。也可以直接打开 index.html；场景已内嵌到脚本，art.svg 保留为独立绘图源文件。上线无需服务器端程序。分享图片使用相对路径，上线后可改为实际站点的完整地址；分享展示由客户端决定。

截图入口：`#scene=sit`、`#scene=breath`、`#scene=tea`、`#scene=sound`。入口只预置画面，不自动播放声音。音频在用户手势后初始化。页面隐藏时暂停音频及呼吸引导。

人数按时间缓慢变化，仅为示意。茶杯数按本地日期保存，仅在当前设备有效；禁用存储时仍可体验。没有账号、表单、追踪或外部素材。最低文字大小 17px，按钮至少 52px，支持安全区及减少动态效果偏好。
